
UniTask
=============

Full-stack project: Spring Boot backend + React (Vite) frontend

Project Structure
-----------------

- `BackendProjet/` — Spring Boot backend (Maven)
- `reactJS/portfolio/` — React frontend (Vite)

Features
--------

- REST API for user management, chat, and related services
- React UI with dashboard, assignments, calendar and chat components

Tech Stack
----------

- Backend: Java, Spring Boot, Maven
- Frontend: React, Vite, Tailwind CSS
- Build tools: `mvnw` (backend), `npm`/`yarn` (frontend)

Prerequisites
-------------

- Java 17+ (or the version defined in `pom.xml`)
- Node.js 16+ and npm or yarn


Where to find code
------------------

- Backend controllers, services, entities, repositories under `BackendProjet/src/main/java/com/Backend/BackendProjet/`
- Frontend source under `reactJS/portfolio/src/` (components, pages, Router)
